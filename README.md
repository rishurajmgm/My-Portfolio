# Rishu Raj — Developer Portfolio

A responsive, dark-themed personal portfolio inspired by modern developer portfolios. Built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract `rishu-portfolio.zip`.
2. Open `index.html` in your browser. (VS Code + Live Server is optional.)

## Personalize before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with your actual email address.
- Replace the GitHub and LinkedIn links with your profile URLs.
- Replace the sample project cards / “Add repository” placeholders with your real project names, descriptions, and URLs.
- Review the skills list so it reflects what you have actually used.
- Confirm your education and certificate details.

## Deploy
You can deploy this static site using Vercel:
1. Put the extracted files in a GitHub repository.
2. Import that repository in Vercel.
3. Keep the framework preset as Other / static and deploy.

Files: `index.html`, `style.css`, `script.js`
